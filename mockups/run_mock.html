Answers and open points

  1. What makes Same as CAM live in Studio (inferred, not proven): Studio's own project file stores a work-origin offset from Makera CAM; a G-code file from Fusion has none, so it's greyed for yours. Ours uses the offset the Carvera community post writes in every header, so it works with plain Fusion output.
  2. Does Anchor 1 need a margin scan? I'd say no, but recommend it: the Scan now button gets a dot when the origin came from Anchor 1 and nothing has been scanned yet. Your call.
  3. Probe Z is back, but only when Z isn't already set: on with Anchor 1 or "where the spindle is", hidden with Current origin or Custom (the 3D probe sets Z).
  4. Leveling touches: the margin scan only shines the laser, but leveling (and Probe Z) touch the stock with the laser probe's tip at each point. Both use the laser probe, so one check covers both.
  5. Which probe is in: the firmware's margin trace only runs as tool 0, and all three probes pass its probe check, so the number alone proves nothing. The pendant measures on the setter and matches the laser probe's learned length (−78.53 on this machine, vs −69.57 for the 3D probe and −72.02 for the rod), then sets M493.2 T0. A 3D probe or rod reading → swap.
  6. Margin during the run: scanning is only a pre-run button now, never inside the job. Leveling and Probe Z run inside the job start (the firmware applies the mesh as it cuts).
  7. Start check: if leveling or Probe Z leaves the laser probe in, the file must have an M6 before its first cut, or Start warns ("T4 would be skipped: the probe would cut").
