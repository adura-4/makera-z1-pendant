Probe in the spindle

The machine only knows a tool number (T9999). If the number is left over from last time, load the probe: it moves to the tool change spot, waits while you swap, then calibrates.

Calibrated on the tool setter

Measures the probe's length on the setter and checks it triggers. Done once each time the probe goes in.

Which probe is in

Each probe trips the setter at its own height. The first calibration of each probe is remembered, so a wrong probe gets caught before it touches your part.
