1 · The Spindle tile: same toggle look as Light / Vacuum
Off = dimmed icon + "Spindle" (like Light when it's off). Running = bright, and the label becomes the live RPM read back from the machine. Tap while off opens the start box (always, it can't be set to "don't ask"). Tap while running = M5 right away, no box. Two looks for "running" below: white like Light/Vacuum (A), or theme blue so it stands out more (B). The icon spins while running, in both.

2 · Start box: opened by tapping the tile while the spindle is off
Same frame as the Move box: blue icon, white title, ✕ top-right, Start at the bottom. Presets fill the box; the box opens holding the last RPM you started with. The exact line it sends is shown, like the Move box. Preset values are placeholders: tell me which you want (the Z1's top speed isn't in the config files; the firmware default is 10,000).
