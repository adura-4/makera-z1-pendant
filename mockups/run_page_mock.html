Run page, redesigned

A proposal for the last page of Run, the one with Start job. Left is the page as it is now; the rest are the new layout in the states it has to handle. The new layout is a mockup only. The app still has the old page.

Job AIR_pendant_block_air_test_Setup1.cnc Estimate 802 s = 13m 22s from the pendant's estimator (JobTime.kt) on this file

What changed from the current page

  • Time first, as the real estimate: 13m 22s, not "about 13 min". It covers the file's moves only; the precheck routine (scan, Z probe, leveling) and the time you spend at tool changes aren't in it.
  • Tool changes as a plain count.
  • Durations read as durations: 13m 22s, 1m 20s, and 1h 05m once a job passes an hour, so they can't be mistaken for a clock time.
  • The tools the job needs, from the file's own tool comments, in the order it uses them, each with its own estimate: the moves from its tool change to the next one. On this job that's 1m 20s and 12m 02s; the real passes took 1m 20s and 11m 46s.
  • "Precheck routine" lists what the machine does first, in the order it runs them, with what each one is. Clearing the old leveling mesh isn't listed: it happens on every start, so it isn't a choice worth showing.
  • Assist shows the modes that are on as their own names, in chips. "None on" when nothing is.
  • The checklist is gone. The laser probe's state is one line inside "Precheck routine", the only place it matters. Anything that stops Start (still loading, off the bed, cuts before M6) shows as one line above the buttons, as now.
  • "Hold · Resume · Reset stay on the main screen." is dropped.

  2. Tool lines. Files from your Fusion post carry a description for each tool. A file with no tool comments would show just T1, T2. Fine?
  3. No leveling mesh line. Should it say anything when an old mesh is cleared, or stay silent as shown?
