Run on a tablet, landscape

The Run flow, a running job, an alarm and Files on a tablet held sideways, in the same two-column layout as the main screen's tablet mockup (left column readouts and controls, right column the big picture). A mockup only: today the tablet shows these screens with the phone layout, stretched.

Window 600 dp or wider (iPad, Android tablet, a wide split-screen) gets this; narrower keeps the phone layout Example job AIR_pendant_block_air_test_Setup1.cnc

What changes from the phone

  • The bed map gets the left column during Run, at full height, so the cutting area, bracket, Z point and leveling dots are big enough to check. The legend sits under it.
  • The step bar moves into the title row, and each page's cards plus Back / Next fill the right column. Nothing on these pages needs to scroll.
  • While a job runs, the dial makes way for a live job map (where the spindle is on the cutting area). The left column has the readouts, the job details and the overrides with Hold / Resume / Cancel job, so it all fits on one screen with no drawer.
  • Alarm is a centered dialog instead of a bottom sheet.
  • Files is a list on the left and the selected file on the right, with Run and its job info, so there's no sheet to open.

Drawn at 1000 x 694 px for a tablet about 1180 x 820 dp, scaled to fit this page. Same colours and wording as the phone app.
