Checked on the Pixel 10 today

  • Android's file picker (step 3): no Cancel, X or back arrow; the ⋮ menu only has Sort by and Show hidden files. The back swipe is the only way out.
  • The pendant doesn't accept shared files today; step 5 needs adding.

Left out: a "jobs folder" listed inside the pendant

I looked at letting the sheet list a folder on the phone so you'd never see Android's picker. Android won't let an app use Download for that ("Can't use this folder", checked on the Pixel), so it only works for files you save into a folder you made yourself. Not in this flow unless you want it.

iPhone / iPad

iOS's picker already has a Cancel button, so step 2's warning is Android only (the sheet could still show, for the "Goes into" line). Sharing to the pendant on iOS needs a separate share extension; Android first.
